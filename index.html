키퍼가 새 방 만들기

키퍼 = 이야기를 진행하는 사람입니다. 지문을 보내고, 필요하면 KPC/NPC 명찰로 바꿔 직접 연기합니다.

탐사자가 방 코드로 들어가기

탐사자 = 플레이어가 맡은 캐릭터입니다. 방 코드를 받은 뒤 자기 캐릭터 이름으로 들어오면 됩니다.

예시 명찰

최요원류재관김솔음이자헌
캐릭터 사진은 사용하지 않습니다. 실제 플레이에서는 이름을 자유롭게 입력합니다.

준비됨

장면

장면 = 이야기를 작은 구간으로 나누는 기능입니다. 인세인을 몰라도 됩니다. 이번 구간에 등장할 탐사자만 고르면 됩니다.

참가자 / 명찰

KPC/NPC = 키퍼가 직접 연기하는 등장인물입니다. 키퍼는 메신저 위쪽 명찰을 바꿔가며 여러 인물을 연기할 수 있습니다.

판정

판정 = 주사위를 굴려 성공/실패를 확인하는 기능입니다. 0.2에서는 풀 캐릭터 시트 대신 필요한 판정값만 등록합니다.

장면별 로그

초보 키퍼 1분 설명

1. 방 만들기
키퍼가 방을 만들고 6자리 코드를 탐사자에게 보냅니다.

2. 장면 만들기
“이번 장면에 누가 등장하는가?”만 고르면 됩니다. 시작 지문은 미리 적어두고 버튼으로 보낼 수 있습니다.

3. 키퍼가 KPC 하기
참가자 탭에서 KPC/NPC 명찰을 추가합니다. 메신저 위에서 명찰을 선택하면 그 인물로 말할 수 있습니다.

4. 대사 / 지문 / 사담
대사 = 캐릭터 말, 지문 = 상황 설명, 사담 = 플레이어끼리 하는 메타 대화입니다.

5. 판정
필요한 판정값만 등록해두고 주사위 버튼을 누르면 성공/실패가 로그에 남습니다.

실시간 접속은 필요 없습니다.
상대가 나중에 들어와도 이전 메시지를 읽고 답할 수 있습니다.
